# CS2-WeaponModelChanger
### 此插件是在插件[equipments](https://github.com/exkludera-cssharp/equipments)基础上进行修改  
属于Equipments的精简修复版
移除了对[Clientprefs](https://github.com/Cruze03/Clientprefs)的依赖  
修复了更换模型后无法还原的BUG  
修复了修改后重进失效的BUG  
修复了选择后模型末尾出现menu的BUG  
___
